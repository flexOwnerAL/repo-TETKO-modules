## English

TETKO Modules is a repository for Python modules for TETKO UserBot.

The repository contains community-created modules that extend the functionality of TETKO.

### Repository Structure

Modules are stored directly in the root of the repository.

```text
repo-TETKO-modules/
├── example.py
├── another_module.py
├── LICENSE.md
├── README.md
└── CONTRIBUTING.md
```
### Modules

Modules can add additional functionality to TETKO, including:

* new commands;
* utilities;
* automation;
* media tools;
* text tools;
* API integrations;
* AI features;
* and other functionality compatible with TETKO.

### Requirements

A module should:

* be written in Python;
* use the supported TETKO module API;
* be compatible with the supported TETKO version;
* contain clear metadata;
* have a clear purpose;
* handle errors correctly;
* not contain malicious functionality.

### Security

Modules must not contain:

* credential or session stealers;
* malicious payloads;
* destructive code;
* hidden data collection;
* unauthorized access mechanisms;
* intentionally harmful functionality.

Suspicious or malicious modules may be rejected or removed.

### Contributing

Contributions are welcome.

You can submit:

* new modules;
* bug fixes;
* improvements;
* compatibility updates;
* documentation.

See `CONTRIBUTING.md` for the contribution rules.

### License

The repository is licensed under the MIT License.

Individual modules may use a different license. Check the license of a specific module before using, modifying, or redistributing it.

### Disclaimer

Modules are created and maintained by their respective authors.

The repository maintainers are not responsible for consequences caused by third-party modules.

## Русский

TETKO Modules — это репозиторий Python-модулей для TETKO UserBot.

### Структура репозитория

Модули находятся непосредственно в корне репозитория.

```text
repo-TETKO-modules/
├── example.py
├── another_module.py
├── LICENSE.md
├── README.md
└── CONTRIBUTING.md
```

### Модули

Модули могут добавлять в TETKO дополнительную функциональность, включая:

* новые команды;
* различные утилиты;
* автоматизацию;
* работу с медиа;
* инструменты для текста;
* интеграции с API;
* функции на базе ИИ;
* другую функциональность, совместимую с TETKO.

### Требования

Модуль должен:

* быть написан на Python;
* использовать поддерживаемый API модулей TETKO;
* быть совместимым с поддерживаемой версией TETKO;
* содержать понятные метаданные;
* иметь понятное назначение;
* корректно обрабатывать ошибки;
* не содержать вредоноса.

### Безопасность

Модули не должны содержать:

* кражу паролей или сессий;
* вредоносные нагрузки;
* разрушительный код;
* скрытый сбор данных;
* механизмы несанкционированного доступа для получения аккаунта;
* намеренный вредонос.

Подозрительные или вредоносные модули могут быть отклонены или удалены.

### Участие в проекте

* новые модули;

* улучшения;
* обновления совместимости;
* документацию.

Правила добавления модулей находятся в `CONTRIBUTING.md`.

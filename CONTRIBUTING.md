# Contributing to TETKO Modules

[English](#english) | [Русский](#русский)

---

## English

If you rewrite an existing module and want your version to become an official TETKO module, submit the rewritten module for review.

### Submission

Send the rewritten module to:

https://t.me/tetkosupport/562

The module must include:

* module file;
* version;
* name;
* description of what the module does.

### Review

After submission, the module will be reviewed by the repository owner.

The owner decides whether the module is suitable for inclusion in the official DLM.

If the module passes the review, it will be added to the future DLM.

### Example

```text
Module: Example
Version: 1.0.0
Description: Adds additional commands and utilities to TETKO.
```

Then attach the rewritten `.py` module.

---

## Русский

Если вы переписываете какой-либо модуль и хотите, чтобы он стал официальным модулем TETKO, отправьте переписанный модуль на проверку.

### Отправка

Отправлять переписанный модуль нужно сюда:

https://t.me/tetkosupport/562

Вместе с модулем необходимо указать:

* файл модуля;
* версию;
* название;
* описание того, что делает модуль.

### Проверка

После отправки модуль проверяет владелец репозитория.

Владелец решает, подходит ли модуль для добавления в официальный DLM.

Если модуль проходит проверку, он будет добавлен в будущий DLM.

### Пример

```text
Модуль: Что то крутое
Версия: 1.0.0
Описание: Что то крутое
```

После этого прикрепите переписанный `.py`-модуль.
